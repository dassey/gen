# gen

## Skyline Forge — 3D-printable city maps

Turn any city, neighbourhood or address into a 3D-printable model, entirely in
the browser. Pick a plate shape, choose which layers you want in which colours,
highlight a route across it, and export a colour 3MF or an STL.

**→ [Open the tool](https://dassey.github.io/gen/skyline/)** · [Documentation](skyline/README.md)

Lives in [`skyline/`](skyline/) as a self-contained static site — no build step,
no server, no account. Enable GitHub Pages on this repository and it is live at
`/skyline/`; move the folder's contents to the repository root if you would
rather have it at the top level.
